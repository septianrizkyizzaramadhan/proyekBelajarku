- .map() : Digunakan untuk mengubah setiap elemen dalam array menjadi nilai baru. Menghasilkan array baru dengan panjang yang sama.

### DAY TWO BELAJAR JS
Di hari kedua gw belajar JS, ge belajar tentang (Destructuring, Rest Parameter & Spread Operator)
materi pertama : 
1. Perbedaan Mendasar Simbol Databound
2. Destructuring Assignment (Membongkar Data)
    Proses "memetik" atau mengeluarkan nilai dari dalam Object/Array ke dalam variabel baru di sebelah KIRI (=).
3. Rest Parameter ... (Menampung Sisa Data)
    Digunakan di sebelah KIRI (=) saat destructuring untuk menampung seluruh sisa data yang tidak dipetik.
4. Spread Operator ... (Menyebar / Menuang Data)
    Digunakan di sebelah KANAN (=) atau di dalam return untuk menuangkan/menggabungkan seluruh isi Object atau Array ke dalam wadah baru tanpa merusak data aslinya (Immutability).

### DAY FIVE BELAJAR JS

Di hari kelima ini gw mulai belajar tentang **LocalStorage**, yaitu cara menyimpan data di dalam browser agar data tetap tersedia meskipun halaman web di-refresh atau ditutup.

Hal yang dipelajari:

- **Menyimpan & Mengambil Data:** Belajar menggunakan `localStorage.setItem()` dan `localStorage.getItem()`.
- **Konversi Format Data:** Memahami kenapa data harus diubah menjadi string JSON menggunakan `JSON.stringify()` sebelum disimpan, lalu dikembalikan ke bentuk Array of Objects menggunakan `JSON.parse()` saat diambil kembali.
- **Penerapan pada State:** Menggunakan LocalStorage untuk menyimpan data aplikasi, seperti daftar catatan (*Notes App*) atau daftar pengeluaran (*Expense Tracker*), secara lokal.
