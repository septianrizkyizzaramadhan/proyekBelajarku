### 3. Praktik
- Membuat Promise sendiri
- Menggunakan setTimeout() dalam Promise
- Mengambil data dari API menggunakan fetch()
- Mengolah response dengan response.json()
- Menangani error menggunakan try...catch
- Memahami penggunaan Promise pada database PostgreSQL (pg)

### 4. Catatan Penting
- Promise digunakan untuk menangani proses asynchronous.
- await digunakan untuk menunggu Promise selesai.
- fetch() menghasilkan Promise.
- response.json() juga menghasilkan Promise.
- await tidak menangani atau memperbaiki error.
- try...catch digunakan untuk menangani error.
